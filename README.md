# Project Idea : 

There are two robots A and B...Robot A moves forward and scouts a region and finds out an object at an angle of 30 degrees and a rack at 120 degrees...After finding the object Robot A sends signal to the Robot B that an object and rack has been found at a distance which is lesser than 25 and 40 cm respectively...Robot B reaches the target location...reracks the object and both the robots return to it origin position

Robot A components : 
1. Arduino Uno
2. Two DC motors
3. One Servo motor
4. Ultrasonic Sensor
5. Red, yellow, green leds
6. 9V battery
7. 3 resistors
8. Breadboard

Robot B components : 
1. Arduino Uno
2. Two DC motors
3. One Servo motor
4. LCD i2c
5. Breadboard
